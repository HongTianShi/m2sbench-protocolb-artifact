# Dimension Stress Audit

Auxiliary matched-summary stress tests over d = 2, 10, 50, 128. Each target and candidate is whitened to the same released summary, then evaluated for exact feasibility, hidden-structure distance, and cost-aware view selection.

The high-dimensional manifold audit is two-sided: full-rank Gaussian controls mark the expected degeneration boundary, while low-rank manifold and mixture structures embedded in high ambient dimension test whether non-Gaussian structure remains hidden by the same compact summary.
