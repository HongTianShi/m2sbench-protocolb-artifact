# Provenance and Generative AI Disclosure

This artifact accompanies the anonymous M2S-Bench CIKM submission.

## Human Responsibility

The benchmark design, task definitions, view menus, cost profiles, experiments,
data processing, numerical claims, final manuscript text, figure/table choices,
and artifact release decisions were selected, verified, and edited by the
authors. The artifact does not contain undisclosed experimental results or
private vendor data generated by AI tools.

## Generative AI Use

The authors used generative AI tools for language polishing, reviewer-style
critique, prompt-assisted schematic drafting, code debugging, and baseline-prompt
stress tests. AI tools were not listed as authors. They were not used as hidden
evaluators and were not allowed to supply qrels, support facts, private labels,
unpaid CE/full scores, or private-test feedback.

Figures 1--3 in the paper were iteratively drafted with prompt-assisted
schematic generation and then manually revised for scientific wording, visual
hierarchy, layout, and benchmark framing. The prompt records are included under
`figure_prompts/`:

- `figure_prompts/figure1_protocol_b_overview_prompt.txt`
- `figure_prompts/figure2_boundary_shift_prompt.txt`
- `figure_prompts/figure3_recoverable_signal_prompt.txt`

These files document visual-drafting provenance only. They are not experimental
records, evaluator data, qrels, support facts, model outputs used for scoring,
or evidence that any data-bearing table/plot was AI-generated. Data-bearing
plots and tables were generated from reported experiment outputs or manually
verified values.

## Artifact Provenance

- Public qrel and structured-evidence slices are documented through the
  `reports/` Markdown/JSON records and the menu declarations under `menus/`.
- Optional licensed-data adapters include scripts and aggregate instructions
  only; returned vendor exports and row-level vendor data are not included.
- Large local corpora, such as the 2Wiki hyperlink paragraph corpus, are treated
  as local inputs. The repository records frozen aggregate reports and selected
  review-facing snapshots, not a redistributed private corpus.
- `docs/2wiki_data_card.md` records the 2Wiki dataset/corpus assumptions, and
  `DATA_LICENSES.md` records code/data/model reuse boundaries.
- Release archives should be produced from `scripts/build_anonymous_release.py`
  and exclude `.git`, caches, bytecode, local logs, model checkpoints, notebook
  checkpoints, and local absolute paths.

## Public-Data Memorization Boundary

The validator can reject forbidden submitted fields, stale cost menus, unknown
views, undeclared tiers, and evaluator-only keys. It cannot prove that an
external model or cache has not memorized public BEIR qrels, 2Wiki support facts,
Wikipedia hyperlinks, or answer strings. Private-test governance therefore uses
withheld evaluator fields, opaque ids, aggregate-only feedback, submission caps,
and optional seed/corpus refreshes under the same schema.
